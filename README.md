# Playerok Cardinal

## Установка одной командой

На Ubuntu нужны Git, Python 3.11+ и модуль `venv`. В терминале запустите:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/Ziw1nFN/playerok-cardinal-public/main/install.sh)"
```

На Windows установите Git и Python 3.11+, затем в PowerShell запустите:

```powershell
irm https://raw.githubusercontent.com/Ziw1nFN/playerok-cardinal-public/main/install.ps1 | iex
```

Установщик предложит ввести данные и запустит бота в текущем терминале. Данные сохраняются в `.env` на вашем устройстве. Для последующего запуска перейдите в папку `PlayerokCardinal` в домашнем каталоге и выполните `venv/bin/python main.py` на Ubuntu или откройте `Start.bat` на Windows.

Бот-помощник продавца на [Playerok](https://playerok.com) по образцу FunPay Cardinal: несколько аккаунтов в одном
боте, автовыдача, автоответчик, приветствие, восстановление и поднятие товаров, Telegram-панель, где всё
настраивается кнопками, и система плагинов.

## Возможности

- 👥 **Мульти-аккаунт** — до 5 аккаунтов Playerok (лимит `MAX_ACCOUNTS` в `.env`) в одном боте и одной панели.
  У каждого свой токен, прокси, User-Agent, настройки, тексты, склад и плагины. Сломанный аккаунт не мешает
  остальным.
- 📦 **Автовыдача** — после оплаты отправляет товар со склада и сам отмечает сделку «Отправлено». Защита от
  двойной выдачи, возврат товара на склад при ошибке, уведомление, если товары кончились.
- 🤖 **Автоответчик** — ответы на команды покупателей (`!помощь`, `!цена` …).
- 👋 **Приветствие** новых покупателей (с паузой в N дней) и 💙 **благодарность за отзыв**.
- ♻️ **Восстановление товаров** — истёкшие и (по желанию) проданные снова выставляются **только бесплатно**.
  Проданный лот — сразу после покупки. Лоты, у которых на Playerok включено «Оставлять в продаже», бот не трогает;
  «📋 Лоты после продажи» в «♻️ Восстановление» показывает, какие лоты Playerok оставляет сам, а какие перевыставит бот.
- ⬆️ **Автоподнятие** (на Playerok платное, по умолчанию выключено) — лимит цены и лимит расходов в день.
- 🧾 **Ответы на сделки** — сообщение покупателю, когда он подтвердил заказ, открыл проблему, получил возврат или
  сделка отмечена «Отправлено» (после автовыдачи не дублируется). Каждый ответ включается отдельно.
- ⏰ **Напоминание подтвердить заказ** — через N часов (1–168) после «Отправлено», если покупатель молчит.
- ⌨️ **Команды в чате Playerok** — напишите покупателю `!выполнить` / `!готово`, и бот отметит его оплаченную
  сделку «Отправлено»; `!вернуть` / `!возврат` — вернёт деньги. Срабатывают только ваши сообщения в личном чате,
  слова меняются в панели.
- 💬 **Шаблоны быстрых ответов** — до 10 шаблонов; кнопки появляются под «✉️ Ответить» на уведомлении, нажатие сразу
  отправляет текст покупателю с его ником.
- 📋 **Сделки и 💬 чаты в панели** — последние продажи с фильтрами (оплачены / отправлены / проблема / все) и
  кнопками «Отправлено», «Возврат», «Ответить»; список личных чатов с историей переписки.
- 🔗 **Синхронизация чатов** — к аккаунту привязывается Telegram-группа с темами: у каждого покупателя своя тема,
  туда приходят его сообщения, фото и события сделок, а ответ, написанный в теме, уходит покупателю (👍 — дошло).
  Ваши сообщения тоже видны: «🤖 Бот» — что бот написал сам, «🧑‍💼 Вы» — ответы из панели и с сайта/приложения
  Playerok (с сайта — с задержкой до 20 секунд и временем отправки: Playerok не присылает боту ваши сообщения,
  бот сам проверяет чаты).
  Кнопки «Сделки чата» / «Шаблоны» прямо в теме; «Отправлено» / «Возврат» — в «📋 Сделки чата» и под событиями
  сделок, если включены «🔘 Кнопки под сделками».
- 📊 **Статистика** по каждому аккаунту и по всем сразу: продажи и выручка за сегодня / 7 / 30 дней / всё время,
  средний чек, сделки в работе, возвраты, топ товаров и выручка по дням. Бот ведёт свой журнал продаж
  (`accounts/<id>/stats.db`), при первом запуске подтягивает последние 1000 продаж с Playerok.
- 🎯 **Профили товаров** — фильтр (слова в названии, цена от–до, игра или категория) и свои настройки:
  поднятие (как обычно / не поднимать / свой интервал и цена), тексты ответов на сделки и ответы на команды.
  Товар берёт первый подходящий профиль; профиль без условий ни к чему не применяется.
- 👥 **Сотрудники** — владелец приглашает людей одноразовой ссылкой (24 часа) и выдаёт права: чаты и ответы,
  сделки, возвраты, статистика, настройки — и аккаунты. Деньги, аккаунты, плагины, поднятие и сотрудники —
  только у владельца (того, кто вошёл по паролю панели). Сотрудник видит только своё меню и свои уведомления.
- 💸 **Автовывод** (только владелец, по умолчанию выключен) — на карту, уже привязанную на Playerok, по СБП или в
  USDT TRC20; по порогу или раз в день, с запасом на балансе и лимитом в сутки. Включается только после ручного
  вывода и кнопки «✅ Деньги пришли». Одна попытка на вывод; при неясном ответе Playerok — пауза до владельца.
  Реквизиты хранятся в `.env` (`ACC_<id>_WITHDRAW_*`), в Telegram видна только маска.
- ⛔ **Чёрный список** — общий для всех аккаунтов.
- 📱 **Telegram-панель** с паролем: уведомления с меткой аккаунта, кнопка «Ответить»; кнопки «Отправлено», «Возврат»
  (с подтверждением) и «Сделка» под событиями сделок — по переключателю «🔘 Кнопки под сделками» в «💬 Сделки и
  чаты» (по умолчанию выключен; в сообщениях, где нужно действие — нет товара, не выдано, чёрный список, — есть
  всегда), переключатель аккаунтов, редакторы текстов, автоответчика, автовыдачи и склада, лимиты,
  прокси, плагины, профиль, логи, перезапуск.
- ✏️ **Переменные в текстах** — `#nickname`, `#item`, `#price`, `#order`, `#order_id`, `#chat`, `#product`,
  `#seller`, `#date`, `#time`. При редактировании бот показывает кнопки, которые копируют переменную, и пример
  готового текста. Старые `$username`, `$product` и т.п. тоже работают.
- 🧩 **Плагины** — `BIND_TO_*` хэндлеры, UUID, включение для каждого аккаунта, страница настроек, свои
  Telegram-команды. Подробно — [docs/PLUGINS.md](docs/PLUGINS.md).

## Установка (Windows)

1. Установите Python 3.11+ (галочка «Add to PATH»).
2. Запустите `Setup.bat` — он поставит зависимости и спросит токены.
3. Запустите `Start.bat`. Остальные аккаунты добавляются в Telegram: меню → `👤 ▾` → «➕ Добавить аккаунт».

Linux / VPS:

```bash
python3 -m venv venv && venv/bin/pip install -r requirements.txt
venv/bin/python first_setup.py
venv/bin/python main.py
```

Пример службы systemd — `scripts/playerok-cardinal.service`, деплой — `bash scripts/deploy.sh`.

## Синхронизация чатов: настройка

1. Создайте в Telegram группу и включите в ней **темы** (настройки группы → «Темы»).
2. Добавьте бота в группу **администратором** с правом «Управление темами».
3. Напишите в группе `/bind` и нажмите на аккаунт. Отвязать — той же кнопкой, `/unbind` или в меню
   «🔗 Синхронизация чатов».

Панель (меню, пароль) работает только в личке с ботом. В группе бот слушает только пользователей панели, а
остальных участников игнорирует. Если бота убрали из группы, синхронизация встаёт на паузу, и сообщения снова
приходят в личку.

## Где взять токен Playerok

Войдите на playerok.com → F12 → Application → Cookies → `https://playerok.com` → значение `token`.
Можно вставить всю строку cookies целиком (вкладка Network → любой запрос → заголовок `cookie`).
Если бот пишет «сработала защита от ботов» — обновите cookies или задайте аккаунту прокси.

## Где что хранится

| Что | Где |
|---|---|
| Секреты: токен Telegram-бота, пароль панели, токены, cookies и прокси аккаунтов (`ACC_a1_TOKEN`…) | `.env` — **никому не отдавайте** |
| Список аккаунтов | `accounts.json` |
| Настройки, тексты, автоответчик, автовыдача аккаунта | `accounts/<id>/settings.json` |
| Склад автовыдачи аккаунта | `accounts/<id>/products/*.txt` |
| Защита от двойной выдачи, приветствия, поднятие, напоминания, команды из чата | `accounts/<id>/cache/` |
| Журнал продаж для статистики | `accounts/<id>/stats.db` |
| Данные плагинов: аккаунта / общие | `accounts/<id>/plugins/` / `storage/plugins/` |
| Пользователи панели, чёрный список | `storage/cache/` |
| Убранные аккаунты и удалённые склады | `accounts/_removed/`, `accounts/<id>/products/_removed/` |

Всё меняется кнопками в Telegram. Запасной путь — отправить боту файл: `.txt` (склад), `.py` (плагин) или
старые `_main.cfg` / `auto_response.cfg` / `auto_delivery.cfg` (применятся к выбранному аккаунту).

## Обновление с v1

При первом запуске v2 старые `configs/`, `storage/` и `.env` копируются в `backup/v1-<дата>/`, аккаунт становится
`a1`, его настройки, склад и защита от двойной выдачи переносятся в `accounts/a1/`, а строки `PLAYEROK_*` в `.env`
комментируются. Автоматического отката на v1 нет: вернуться можно только вручную из `backup/`, и тогда склад
вернётся к моменту обновления — перед этим сверьте его, иначе проданные после обновления коды выдадутся повторно.

## Благодарности

Работа с Playerok — библиотека [PlayerokAPI](https://github.com/alleexxeeyy/PlayerokAPI) (MIT, © alleexxeeyy),
лежит в `playerokapi/` (коммит `1c9564d`, 02.11.2026). Playerok не даёт официального API — библиотека неофициальная
и может перестать работать после изменений на сайте.

Наши правки библиотеки (перенести при её обновлении):
1. `account.py`: `Account` больше не синглтон — каждый аккаунт отдельный объект; `get_account()` возвращает
   последний созданный.
2. `listener/listener.py`: `EventListener.stop(timeout)` — флаг остановки во всех циклах, закрытие WebSocket,
   выход из `listen()`.
3. `account.py`: параметр `retries` у `Account.request` и `Account.send_message` (по умолчанию 3, как было).
   `Cardinal.send_once` передаёт `retries=1`, чтобы после таймаута ответ покупателю не ушёл повторно.
4. `account.py`: параметр `retries` у `Account.request_withdrawal` — автовывод делает одну попытку, без повторов.
